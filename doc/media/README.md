# Media

[← README](../README.md)

Photos and video of the system running live on the DE1-SoC. The main README's Demo section points at these exact names, so once a file is added here, uncomment its line in the README.

| File | What to capture |
|---|---|
| `demo.mp4` | Full demo: walk through every filter key, a snapshot (Space / V / C), and SW0 edge detection |
| `demo.gif` | Short loop (5 to 10 s, under 10 MB) cut from the video, shown at the top of the README |
| `board_setup.jpg` | DE1-SoC with camera, PS/2 keyboard and VGA monitor connected |
| `live_kaleidoscope.jpg` | Monitor showing filter 3 |
| `live_dither.jpg` | Monitor showing filter 5 |
| `live_ascii.jpg` | Monitor showing filter 6 |
| `live_edge.jpg` | Monitor with SW0 on |
| `live_glitch.jpg` | Monitor showing filter 9 |

Videos over about 10 MB are better uploaded to YouTube or as a GitHub release asset and linked from the README.
